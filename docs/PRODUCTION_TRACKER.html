Production gates

  • Functional: P0 end-to-end, không silent failure.
  • Data: source, last checked, verification state, freshness.
  • Security: HTTPS, secrets ngoài Git, rate limiting, auth tests.
  • Reliability: backup/restore, health/logging, monitoring, timeout/retry.
  • Performance: mobile 4G, trip latency, 3D FPS, load test.
  • UX: first-time user, permission denial, poor network, loading/error/success.
