# Hoàn tất tách dự án: huevivu-trainer

Mình đã tạo xong một project độc lập có tên là `huevivu-trainer` và thực hiện các chỉnh sửa để nó chạy hoàn toàn độc lập với app chính. Dưới đây là cách hoạt động:

## 1. Ứng dụng HueViVu Trainer (Dành cho VPS)
- Project mới nằm tại: `scratch/huevivu-trainer`.
- Ứng dụng này là một Next.js app độc lập, không dùng chung database với app chính.
- Khi thêm/sửa/xóa quy tắc trên giao diện của app này, dữ liệu sẽ được lưu thẳng vào một file là `bot_knowledge.json` nằm ở thư mục gốc của project `huevivu-trainer`.
- Bạn có thể nén thư mục này lại, đẩy lên VPS, chạy lệnh `npm install` và `npm run build` -> `npm run start` là có thể host công khai cho team vào train bot.

## 2. Ứng dụng HueViVu chính (`huevivu-nextjs`)
- Mình đã **dọn dẹp sạch sẽ** các code API và giao diện admin cũ trong app này.
- Trong file `src/lib/ai.ts`, thay vì đọc từ DB, chatbot giờ đây sẽ tự động tìm kiếm file `data/bot_knowledge.json`.
- **Cách cập nhật kiến thức**: Khi team bạn train xong trên VPS, bạn tải file `bot_knowledge.json` từ VPS về và chép đè vào thư mục `data/` của `huevivu-nextjs` là chatbot sẽ tự động "khôn" lên theo ý muốn.

## Thử nghiệm
Để chạy thử `huevivu-trainer` trên máy tính, bạn hãy mở một terminal mới và chạy:
```bash
cd scratch/huevivu-trainer
npm run dev -p 3001
```
(Chạy ở port 3001 để không đụng với app chính đang chạy ở 3000). Sau đó truy cập `http://localhost:3001` để nhập dữ liệu.
